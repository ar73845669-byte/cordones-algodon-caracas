# Cordones de Algodón Trenzado con Alma — Caracas

Sitio web interactivo y catálogo digital para la venta y distribución de cordones de algodón trenzado con alma (núcleo reforzado), calidad de importación en Caracas, Venezuela.

## 🧵 Características

- **Catálogo en Vivo**: 11 colores disponibles en stock con previsualización dinámica.
- **Visualizador 3D (Three.js)**: Carrete interactivo 3D con rotación orbital (`OrbitControls`).
- **Calculadora de Pedidos**: Estimación instantánea de metros y costo total ($0.50 / metro).
- **Integración con WhatsApp**: Enlace directo para concretar pedidos con mensaje autogenerado.
- **Galería Polaroid & Arte**: Muestra de aplicaciones reales (calzado, macramé, confección, bisutería) y arte generativo en puntillismo.
- **100% Responsive**: Adaptado para navegación fluida en dispositivos móviles y de escritorio.

## 🚀 Tecnologías

- **HTML5** & **CSS3** (Variables CSS, efectos glassmorphism, tipografía Google Fonts: *Plus Jakarta Sans*, *Fraunces*, *Caveat*).
- **JavaScript (Vanilla)** para reactividad y lógica de negocio.
- **Three.js** para renderizado 3D en WebGL.

## 💻 Visualización Local

Para ver el proyecto en tu navegador:
1. Abre `index.html` directamente en tu navegador web, o
2. Ejecuta el servidor local en PowerShell con:
   ```powershell
   .\server.ps1
   ```
   y abre `http://localhost:8000`.
